Bullion Ledger Guide
An open-source, private gold and silver portfolio tracker powered by automated daily price feeds.
Getting Started in 3 Easy Steps
1. Create Master Password
Navigate to the Purchases tab and set a master password. This initializes your client-side AES-256 encrypted database.
2. Log Physical Holdings
Add purchase records (Date, Asset, Purity, Weight, Total Cost). Historical market rates auto-fill when you select a past date.
3. Track Profit & Valuation
View real-time total portfolio value, overall profit/loss, and historical rate comparison charts on your Dashboard.
Summmary, in short
  1. Check the Overview tab for today's prices and calls.
  2. Browse or extend price history under History.
  3. Open Purchases, set a password once, and start logging what you've bought.
  4. Come back anytime — the scraper keeps prices current on its own.
What is Bullion Ledger?

A free, self-updating tracker for gold & silver prices, built to run entirely on GitHub with no server and no PC left running. A GitHub Actions workflow scrapes daily rates and commits them to bullion_history.csv in this repo; GitHub Pages serves this dashboard, which reads that CSV directly and renders the charts, valuation calls, and your personal purchase log.

Overview tab

Current price for each metal with week-over-week change, ATH/ATL badges, trend charts, and a per-metal call — Strong Buy through Avoid Buying Now — based on where today's price sits in its full historical range (percentile-based, not financial advice).

History tab

The full price table the scraper has built up, plus a form to add a rate manually for a date the scraper missed (holiday, site outage, etc). Submitting that form opens a pre-filled GitHub Issue — click Submit new issue there and an automated workflow writes it into the CSV within seconds. You'll need to be logged into GitHub for that step.

Purchases tab

Your personal investment log — kept separate from the public price data. First time you open it, you'll set a master password; your entries are then encrypted (AES-256) before being saved, so nothing readable sits in your browser at rest. Pick a Date, Asset, and Purity and the day's rate fills in automatically from the ledger; enter either Quantity or Total Paid and the other calculates for you. Every entry can be edited later, and 🔒 Lock this tab clears your session immediately.

Forgetting your password means that data can't be recovered — there's no backdoor by design, so keep your password somewhere safe.

Key System Features
Feature Description
Automated Scraper GitHub Actions fetches prices automatically every morning (06:00 UTC/11:30 IST) and commits clean records to CSV.
AES-256 Encryption All personal holdings are encrypted in your local browser storage using PBKDF2 key derivation.
Manual Price Updates Submit missing historical rates directly through the History tab using automated GitHub Issues.
Interactive Management Edit or delete purchase entries anytime via the modal dialog with automated math recalculations.
🔒 Privacy & Security Guarantee: Your financial records remain strictly inside your device's browser memory (`localStorage`). No personal purchase details, quantities, or financial figures are sent to GitHub or any cloud server.
Cross-Device Sync ✕
Purchases stay encrypted (AES-256-GCM) before ever leaving this browser. GitHub only ever sees ciphertext. Use a Fine-Grained PAT scoped to Gists: Read and write only — nothing else.
